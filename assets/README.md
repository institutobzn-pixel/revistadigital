# assets/

Coloque aqui os arquivos de mídia da revista:

- **Logo oficial** do Instituto (ex.: `logo.svg`, `logo-navy.png`, `logo-branco.png`).
- **Fotos** de cada edição (ex.: `edicao-01-capa.jpg`).

Depois, referencie-os no `index.html`. Veja o `README.md` da raiz para os exemplos de como trocar o logo e as fotos.

Dica: use fotos otimizadas para web (largura ~1600px, formato `.jpg` ou `.webp`) para a revista carregar rápido.
